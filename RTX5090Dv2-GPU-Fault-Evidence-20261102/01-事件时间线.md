## 口径说明

- 只以**已有原始事件与转储双重核验**的这三组事故作为正式对外证据。
- 不把普通 Event ID 153 单条错误等同于 FECS/TDR 完整故障，也不把 WER 重复上报条数当作独立故障次数。
- Windows Event ID 13 与 NVIDIA 技术文档中的 Xid 13 不是同一种编号体系。
