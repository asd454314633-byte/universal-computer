# RTX 5090 D v2 显卡故障检测证据公开页

> **用途：向原销售店铺和显卡制造商申请正式故障受理、质量检测和书面检测结论。**
>
> 资料整理日期：2026-11-02。文中时间均为北京时间（UTC+8）。

## 申请事项

本人购买的 **NVIDIA GeForce RTX 5090 D v2（24GB）** 显卡，在正常使用过程中多次出现 GPU 严重异常及 Windows 显卡引擎超时恢复事件。相关故障不是仅凭用户主观感受判断，而有 Windows 原始系统事件、实时内核转储及独立校验记录支持。

**请销售者/厂家正式受理质量问题，安排可复核的检测，提供书面检测结论。** 如认为显卡本身不存在质量问题，请给出检测环境、检测项目、结果及解释已记录异常的依据。

本证据页只用于报障及申请检测，**不预先提出更换或其他特定处置要求**。

## 已核实的核心事实

1. 2026-09-08 17:31、2026-11-02 11:48、2026-11-02 20:15，共有三组对应的 NVIDIA GPU **FECS UCODE Fatal / PF FLR / TDR** 事件和内核转储。
2. 三份已经独立核验的 Windows 实时内核转储，错误分类均为 **0x141 VIDEO_ENGINE_TIMEOUT_DETECTED**；发生于 **616.56、617.42** 两个不同的 NVIDIA 显示驱动版本。
3. 本人未进行显卡手动超频、降压或人为提高功率限制。已保存的本机配置核查显示核心/显存频率偏移为 **0**、未启用电压解锁、功率上限 **575 W，与设备报告默认值一致**。
4. 2026-11-02 20:15 故障发生前后，逐秒监控中 **20:15:17** 的采样功耗 **137 W**、GPU 温度 **51°C**；该次异常不位于该监控窗口内的功耗或温度峰值。
5. 对于三份转储、故障事件及其驱动版本，已有文件校验与独立复核。**现有证据确认故障事实，但尚不预判究竟是显卡硬件、驱动还是外部平台因素；请厂家通过独立检测核实。**

## 原始文件的提交方式

三份原始 `.dmp` 已保存，且有完整 SHA256；由于内核转储可能包含系统内存数据，本公开页**不公开原始转储和用户隐私数据**。如官方售后确需二进制原件、购买凭证或产品序列号，可通过售后工单的非公开渠道提供并核验。

## 证据解释边界

- `0x141` 是 Windows 视频引擎超时**实时转储类别**，不等于整机蓝屏；参数2与 NVIDIA 显示驱动模块相关，但这一字段不能独立区分硬件和驱动根因。
- 多次独立事件跨越不同显示驱动版本，不足以排除所有软件因素，也不能据此认定显卡已发生物理损坏。
- 本公开材料不包含推测性历史转储数量、无完整核实的故障次数、内部开发项目和其他无关个人信息。

微软官方定义：[VIDEO_ENGINE_TIMEOUT_DETECTED (0x141)](https://learn.microsoft.com/en-us/windows-hardware/drivers/debugger/bug-check-0x141---video-engine-timeout-detected)。
