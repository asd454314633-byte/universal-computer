## 一、正式质量异议与受理请求

本人购买并按常规方式使用的 **NVIDIA GeForce RTX 5090 D v2（24GB）** 显卡，多次发生严重 GPU 异常，Windows 记录了完整的 GPU 错误及恢复过程，并生成实时内核转储。故障不仅是某个软件窗口的提示，而有系统事件与二进制转储共同佐证。

**现正式提出商品质量与运行稳定性异议，要求销售者登记并书面确认受理；优先由厂家安排工程师上门/现场检测，在不破坏现有故障证据的前提下核查显卡及其使用环境。**

如当前无法安排上门，请先通过平台工单说明具体原因及可行的远程初步核验方式。**本次申请不主动提出寄送显卡、维修、更换、退款或其他处置方式。**

请记录故障发现时间与受理时间，并通过平台工单提供受理编号或书面确认。

## 三、检测及书面答复要求

1. **先正式受理并保护现场**：保全既有系统事件、转储及设备状态；不要将消费者自行清除驱动、重装系统或重复高负载测试作为登记故障的先决条件。
2. **优先上门/现场核验**：综合查看原始故障记录与设备环境；如需验证典型使用场景，请覆盖长时间图形/计算任务以及负载和显存占用变化，而非只看桌面显示是否正常。
3. **给出可复核的书面结论**：载明检测平台、驱动版本、负载类型、测试持续时间、具体项目和结果，并解释上述三次已经核实的 GPU 致命事件及 `0x141` 转储。一次短时未复现，不应替代对既有故障记录的分析。
4. **如提出人为使用、安装或其他因素的判断**，请指明具体事实、检测方法、数据及因果依据，不以未经证实的推测拒绝受理。
